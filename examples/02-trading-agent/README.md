# Trading Agent

Policy-gated swap quotes via Uniswap / EVM MCP tools.

## Run

```bash
pnpm --filter @abstraxn-examples/trading-agent dev
```

http://localhost:3002

On boot the example applies a **$50/day spend policy** (see `lib/session.ts`).
