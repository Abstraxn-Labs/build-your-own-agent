# Fraud Policy Agent

**Honest framing:** policy-enforced agent + monitoring signals — not a full AML product.

Applies daily spend cap + recipient blacklist + native amount limit on boot.

## Run

```bash
pnpm --filter @abstraxn-examples/fraud-policy dev
```

http://localhost:3004
