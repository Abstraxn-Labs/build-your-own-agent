# Next Agent Template

Copy this folder to `examples/NN-name` to start a new use case.

## Customize

1. `lib/agent.ts` — name, system prompt, tool set
2. `app/page.tsx` — empty-state prompt (optional)
3. `package.json` — name + `dev` port
4. Add `README.md` + `CONTENT.md`

## Run

```bash
# from repo root
pnpm install
pnpm --filter @abstraxn-examples/next-agent-template dev
```
